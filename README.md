# Журнал группы

Практика по теме «Fork и Pull Request».

**Ваша задача:** добавить в журнал своё имя и группу через Pull Request.

У вас нет прав на запись в этот репозиторий. Так устроены почти все открытые
проекты на GitHub: вы делаете свою копию (форк), вносите изменения в неё
и просите автора принять их к себе (Pull Request).

---

## Шаг 1. Сделайте форк

Нажмите кнопку **Fork** в правом верхнем углу этой страницы, затем **Create fork**.

В вашем аккаунте появится копия репозитория: `github.com/ВАШ-ЛОГИН/git-group-journal`.

## Шаг 2. Склонируйте свой форк

Клонируйте **свой форк**, а не этот репозиторий. Адрес возьмите на странице
форка: кнопка **Code** → вкладка **SSH**.

```bash
git clone git@github.com:ВАШ-ЛОГИН/group-journal.git
cd group-journal
```

## Шаг 3. Создайте ветку

```bash
git switch -c add-ivanov
```

Вместо `ivanov` напишите свою фамилию латиницей.

## Шаг 4. Добавьте свою запись

В папке `journal` создайте файл со своей фамилией латиницей, строчными
буквами. Например, `journal/ivanov.md`.

Проще всего скопировать пример:

```bash
cp journal/example.md journal/ivanov.md
```

Откройте свой файл в редакторе и впишите свои данные:

```
Имя: Иван Иванов
Группа: ИС-21
```

> Создайте **свой** файл. Чужие файлы и `example.md` не меняйте.

## Шаг 5. Сделайте коммит

```bash
git add journal/ivanov.md
git commit -m "docs: добавить Иванова Ивана в журнал"
```

## Шаг 6. Отправьте ветку в свой форк

```bash
git push -u origin add-ivanov
```

## Шаг 7. Откройте Pull Request

Откройте свой форк на GitHub. Появится жёлтая плашка
**Compare & pull request** — нажмите её.

Проверьте, что запрос идёт **из вашего форка в этот репозиторий**:
слева этот репозиторий и ветка `main`, справа ваш форк и ваша ветка.

Напишите короткое описание, например «Добавил свою запись в журнал»,
и нажмите **Create pull request**.

## Шаг 8. Дождитесь проверки

Преподаватель посмотрит ваш Pull Request. Если всё в порядке, он примет его,
и ваш файл появится в журнале.

Если попросят что-то исправить, правьте в той же ветке:

```bash
git add journal/ivanov.md
git commit -m "docs: исправить запись в журнале"
git push
```

Новый Pull Request открывать не нужно, старый обновится сам.

## Проверьте себя

- [ ] Сделан форк
- [ ] Склонирован свой форк, а не оригинал
- [ ] Работа сделана в отдельной ветке
- [ ] Добавлен только свой файл `journal/фамилия.md`
- [ ] Открыт Pull Request

## Если что-то пошло не так

| Что видите | Почему | Что сделать |
|---|---|---|
| `git push` пишет, что нет доступа (`Permission denied` или `403`) | Склонировали этот репозиторий, а не свой форк | Проверьте `git remote -v`: там должен быть ваш логин. Если нет, склонируйте свой форк заново |
| Нет плашки **Compare & pull request** | Ветка ещё не отправлена или плашка уже скрылась | Вкладка **Pull requests** → **New pull request** → выберите свою ветку |
| В Pull Request видны изменения в чужих файлах | Изменили не только свой файл | Верните чужие файлы как было, сделайте коммит и `git push` |
